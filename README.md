# Grok Bot 团队创建器

一个 Grok Bot Skill：把任何反复要做的大活，拆成一支**一个 bot 只干一件事、靠文件交接、只在决策点等人**的 Grok Bot 团队，然后帮你建好、接通、跑通第一轮。编辑部、调研组、产品流水线、运营组，什么领域都可以。

## 里面有什么

- `SKILL.md`：Skill 本体。七条原则，加上从“要不要团队”到“建队、冒烟测试、交付”的八个步骤，以及共享规则块和个人指令两份模板。
- `examples/ai-tools-weekly/`：一支三人试跑团队（采集、核实、撰稿）的完整描述和一轮真实产出，可以对照着看每一步落地成什么样。

## 怎么用

1. 把 `SKILL.md` 的全文（或者这个仓库的链接）发给你的 Grok Bot，请它存成一个 skill。
2. 之后跟它说你想搭什么团队，比如“我想搭一支每周出一份行业周报的团队”。它会先判断值不值得搭团队，再一次问你一个问题，把方案（成员表、流水线图、人类关口、做不到的事）交给你确认。
3. 你点头后，它建好每个 bot，建共享目录、`HANDOFF.md` 和每个 bot 的状态文件，用一个最小的题目跑一整轮，再把团队名单和启动口令交给你。

## 七条原则

1. 一个 bot 一件事，并写明绝不碰的相邻工作。
2. 交接靠文件，消息只当门铃。每个 bot 只写自己的状态文件，`HANDOFF.md` 由协调人汇总；门铃附验收标准。
3. 一个文件只有一个写入者。
4. 前一步没 DONE 就不开工。停下来分六种状态：完成、待输入、待授权、受阻、达上限、被用户叫停。返工一轮审、一轮定向修，轮次跨 bot 累计，还不过就报给用户。
5. 事实和推断分开写。
6. 人只守决策点，别的 bot 转述的批准不算数。
7. 小步跑通再扩编。

`examples/ai-tools-weekly/` 是 2026-10-24 的试跑记录，当时用的是旧版交接方式（各 bot 直接追加 `HANDOFF.md`，只有 DONE 和 BLOCKED 两种状态），按原样保留。
